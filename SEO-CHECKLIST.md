# DenZest SEO / Local SEO launch checklist

## On-page
- Unique title and meta description on every indexable page
- One clear H1 per page
- Descriptive internal links
- Canonical URL on each page
- Mobile responsive layout
- Lightweight CSS / no framework dependency

## Local SEO - Section 14
- Create and verify the DenZest Google Business Profile using the real business information.
- If DenZest operates as a service-area business without a customer-facing office, configure the profile as appropriate rather than using a virtual office.
- Keep the website NAP/contact information consistent with the real business details.
- Add a genuine Pune service-area description and only list areas actually served.
- Build useful Pune-focused pages: dental laboratory Pune, zirconia dental lab Pune, pickup & delivery Pune.
- Add useful area pages only when DenZest has meaningful local information/service relevance; avoid near-duplicate doorway pages.
- Collect genuine clinic reviews only after real customer relationships exist; never publish fabricated reviews.
- Add Organization structured data. Add LocalBusiness structured data only once real business address/service details are known and appropriate.
- Verify the website in Google Search Console and submit sitemap.xml.
- Keep Google Business Profile, website, phone and email current.

## Analytics
- Add GA4 Measurement ID.
- Add Microsoft Clarity Project ID.
- Test CTA events for phone, WhatsApp and email.

## Forms
- Use a business-owned Google Workspace account.
- Separate Clinic Partnership, Lab Partnership and General Contact forms.
- Avoid collecting patient/medical case data in these public forms.
